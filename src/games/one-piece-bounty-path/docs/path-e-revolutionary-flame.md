# Path E - Light the Flame (revolutionary trunk)

One full tree branch: Baltigo oath to Mariejois fire.
7 options per node. Trunk marked ★ (Dragon's Faith combo completes in R2, no plotholes).
Siblings carry named stubs + premise (zero dead ends).
Unique finale leaf: LIBERTY_PYRE.

## Legend

- `P / N / D / I / C / K` = Power / Notoriety / Defiance / Influence / Cunning / Knowledge (% deltas, clamped 0-100, diminishing past 80).
- `B` = bountyBase range (millions of belly, rolled per run). Bounties in R2-R5 represent Δ additions onto the baseline.
- `+flag` = hidden flags (combos + gates, see graph.md).
- `(stub: ...)` = continuation premise, authored in the next pass.

## Canon logic rules (no plotholes)

- Dragon's Faith combo needs BOTH +revolutionary and +celestial_crime — trunk swears the oath in R1, strikes the Holy Land in R2.
- Power ladder: R1-R2 organize and hide (agitators, not armies), R3 supply lines, R4 open strikes, R5 legend feats.
- No killing Dragon's commanders for shock value (canon fixed — Sabo, Ivankov, Kuma survive this tree).
