One full tree branch: prison gates to Marineford flag.
7 options per node. Trunk marked ★ (no Admiral kills before R5, no plotholes).
Siblings carry named stubs + premise (zero dead ends).

## Legend

- `P / N / D / I / C / K` = Power / Notoriety / Defiance / Influence / Cunning / Knowledge (% deltas, clamped 0-100, diminishing past 80).
- `B` = bountyBase range (millions of belly, rolled per run). Bounties in R2-R5 represent Δ additions onto the baseline.
- `+flag` = hidden flags (combos + gates, see graph.md).
- `(stub: ...)` = continuation premise, authored in the next pass.

## Canon logic rules (no plotholes)

- People's Pirate combo needs BOTH +liberator and +folk_hero — trunk frees the cages in R2, shields the escapees in R4.
- Power ladder: R1-R2 raid and dodge (no Magellan duel before R3), R3 warden-max (Magellan hunt), R4 fleet feats, R5 legend feats.
- Magellan survives the trunk duel (canon fixed — poison always wins the rematch clause, ye escape, never execute).
