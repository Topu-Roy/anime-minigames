# Path D - Hunt a Yonko (hunter trunk)

One full tree branch: insulted flag to Yonko blood.
7 options per node. Trunk marked ★ (commander-max rung at R3, one Yonko feat at R4).
Siblings carry named stubs + premise (zero dead ends).
Unique finale leaf: BLOOD_PRICE.

## Legend

- `P / N / D / I / C / K` = Power / Notoriety / Defiance / Influence / Cunning / Knowledge (% deltas, clamped 0-100, diminishing past 80).
- `B` = bountyBase range (millions of belly, rolled per run). Bounties in R2-R5 represent Δ additions onto the baseline.
- `+flag` = hidden flags (combos + gates, see graph.md).
- `(stub: ...)` = continuation premise, authored in the next pass.

## Canon logic rules (no plotholes)

- No killing a Yonko (canon fixed — Emperors fall only to volume-scale wars). R4 earns blood + sunken fleets, never a corpse.
- Power ladder: R1-R2 taunt and dodge (provoke, never duel), R3 commanders max (King the Wildfire), R4 one Yonko feat (wound or sink fleet), R5 legend feats.
- Yonko Slayer combo needs BOTH +yonko_blood and +fleet_killer — trunk collects blood in R2, fleet in R4.
