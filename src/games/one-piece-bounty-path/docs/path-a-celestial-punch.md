# Path A - Punch a Celestial (seven sins trunk)

One full tree branch: seven scattered origins, Sabaody punch leads the sky trunk.
7-8 options per node. Sky trunk marked ★ (breaks off-canon after R2).
Siblings carry named stubs + premise (zero dead ends).
Two full leaves: NOAH_PUSH (canon dive chain) + STORM_THRONE (sky trunk).

## Legend

- `P / N / D / I / C / K` = Power / Notoriety / Defiance / Influence / Cunning / Knowledge (% deltas, clamped 0-100, diminishing past 80).
- `B` = bountyBase range (millions of belly, rolled per run). Bounties in R2-R5 represent Δ additions onto the baseline.
- `+flag` = hidden flags (combos + gates, see graph.md).
- `(stub: ...)` = continuation premise, authored in the next pass.

## Canon logic rules (no plotholes)

- Glyphs: cache ≠ read. Reading needs robin_ally, scholar, or vegapunk_tech. Knowledge (K) increases ONLY when read or translated; cached rubbings alone grant 0 K.
- Power ladder: R1-R2 outrun only (no Admiral kills), R3 commanders max, R4 island feats, R5 one legend feat.
- Geography & Transit: One location per node, explicit transit stated in choices (e.g., thermal ocean currents for sky ascent, 10,000m deep sea descent for Fish-Man Island).

## Final Bounty Summary

- Standard combat/sky progression scales logically from a 200M baseline up to 700M–1.2B for major island victories, sovereign claims, or fleet obliterations.
- Stealth, frame-up, and political pardon paths cap early between 250M–350M due to low World Government threat perception.
- Unlocking the Void Century broadcast climax scales to 1.5B–2.5B, reflecting an existential threat to the World Government's global authority.
