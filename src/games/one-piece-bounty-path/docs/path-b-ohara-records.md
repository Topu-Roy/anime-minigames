# Path B - Steal Ohara Records (scholar trunk)

One full tree branch: burning library to Loguetown podium.
7 options per node. Trunk marked ★ (reader earned mid-path, no plotholes).
Siblings carry named stubs + premise (zero dead ends).
Unique finale leaf: TRUTH_PODIUM.

## Legend

- `P / N / D / I / C / K` = Power / Notoriety / Defiance / Influence / Cunning / Knowledge (% deltas, clamped 0-100, diminishing past 80).
- `B` = bountyBase range (millions of belly, rolled per run). Bounties in R2-R5 represent Δ additions onto the baseline.
- `+flag` = hidden flags (combos + gates, see graph.md).
- `(stub: ...)` = continuation premise, authored in the next pass.

## Canon logic rules (no plotholes)

- Glyphs: cache ≠ read. Trunk earns reader Saul in R3 (giant Ohara scholar recovering from frostbite). Knowledge (K) increases ONLY when read or translated; cached rubbings alone grant 0 K.
- Buster Call already happened: Ohara is ash. No saving the island (canon fixed).
- Power ladder: R1-R2 flee and hide (scholars, not fighters), R3 allies, R4 truth, R5 podium.
