# Path G - Race for Laugh Tale (racer trunk)

One full tree branch: stolen rubbing to the final island.
7 options per node. Trunk marked ★ (reader earned in R2, read gated in R3, no plotholes).
Siblings carry named stubs + premise (zero dead ends).
Unique finale leaf: TALE_END.

## Legend

- `P / N / D / I / C / K` = Power / Notoriety / Defiance / Influence / Cunning / Knowledge (% deltas, clamped 0-100, diminishing past 80).
- `B` = bountyBase range (millions of belly, rolled per run). Bounties in R2-R5 represent Δ additions onto the baseline.
- `+flag` = hidden flags (combos + gates, see graph.md).
- `(stub: ...)` = continuation premise, authored in the next pass.

## Canon logic rules (no plotholes)

- Glyphs: cache ≠ read. Trunk earns reader scholar in R2 (a kidnapped Ohara-trained translator). Knowledge (K) increases ONLY when read or translated; cached rubbings alone grant 0 K.
- Road race: four Road Poneglyphs exist (canon fixed). Trunk holds copies, never all four originals — Laugh Tale stays a horizon, never a conquered island.
- Power ladder: R1-R2 steal and dodge (thieves, not Emperors), R3 readers, R4 blockade runners, R5 legend feats.
